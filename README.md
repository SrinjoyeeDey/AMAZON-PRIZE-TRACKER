🛒💸 AMAZON PRICE TRACKER 💸🛒  
===================================================

🔥 Never miss a SALE again! This Python-powered tool scrapes live product prices from Amazon and emails you the moment your dream deal goes LIVE!  

Built with 💻 Python + ❤ Passion for saving money!

---------------------------------------------------

✨ WHAT IT DOES:
---------------------------------------------------
✅ Tracks product price from Amazon  
✅ Sends you an email alert when price drops below your target  
✅ Helps you grab the BEST deals before they're gone  
✅ Keeps your credentials safe using environment variables  

---------------------------------------------------

⚙ TECHNOLOGIES USED:
---------------------------------------------------
🐍 Python  
🌐 Requests  
🧪 BeautifulSoup  
📧 SMTP (Gmail)  
🔐 dotenv  

---------------------------------------------------

🚀 HOW TO USE:
---------------------------------------------------
1. Clone this repo  
2. Create a .env file in the same directory with:
   my_email=your_email@gmail.com  
   password=your_generated_app_password  
3. Update your product URL and target BUY_PRICE in the script  
4. Run the script — and sit back as the bot hunts deals for you!  

Pro Tip: Use PythonAnywhere or a scheduler to run this script daily!
